# Prompts that work

Copy these in order. Each one ends a stage. Replace the parts in brackets.

## 0. Before you start, gather this

The single biggest time saver is giving the cast sheet up front. Every item below was a correction we had to make later.

```
Cast (as they looked at the time of the story):
- [Name]: [skin tone], [hair colour and style], [height in feet and inches], [glasses or not], [build]
- ...
Era and place: [summer 1998, shared student apartment]
Clothes: [t-shirts, it was summer]
Who narrates: [name]. Other voices you will hear: [name, name]
Where we recorded: [a long dinner table, at night, about a dozen of us] (photo attached)
Things I do not want: [floating text labels, anyone looking like a kid, exaggerated heights]
```

## 1. Kick off

```
Use the memo-toons skill. My project folder is projects/[name] and the memo is [file].
You are my creative director. Transcribe it, then tell me the stories you hear and
ask me the questions you need answered. Here is my cast sheet: [paste]
```

## 2. The cut

```
Propose the edit. Tighten it so it flows, cut the rambling, reorder lines if a story
lands better. Show me the kept lines by chapter with running time, then cut the audio
so I can listen.
```

After listening: `Cut the line at [time]. Move [line] before [line]. The ending drags.`

## 3. The look

```
Give me three different art directions as test frames of the same scene. I will pick one.
```

## 4. Characters

```
Do character sheets one person at a time. Show me each and wait for my yes.
I am attaching a photo of [name]. The photo is recent, the story is [N] years ago.
```

Then: `Build the lineup with these heights: [name 5'8, name 6'5]. Show it to me.`

## 5. Storyboard and shots

```
Storyboard against the cut audio. Draw every shot. Before you show me anything, check each
frame yourself for head count, heights against the lineup, glasses, hair and clothes.
Then show me contact sheets.
```

## 6. First cut

```
Assemble a first cut with stills and slow camera moves only. No animation yet.
```

## 7. Notes

Give notes with timecodes, one issue per line. The agent fixes faster from this than from a paragraph.

```
0:55 the doorway shot, I hate the movement, make it a still
1:49 Ana is taller than Ben here, they are the same height
3:19 remove the floating text
general: everyone at the dinner table looks too old
```

## 8. Animation

```
Add limited animation: one small moving detail per shot where it earns it, like smoke,
tears, flames or a kicking leg. Faces stay frozen. Show me the change map for every
cycle before you render. Here is a film whose movement I like: [local file path]
```

Give a local video file, not a link. The agent can sample frames from a file but cannot watch a website.

## 9. Sound and credits

```
Add sound effects where they help a joke, a quiet room tone, and my credits song
starting at [1:03] for [30] seconds. Credits copy: [who is credited as what].
Remember you cannot hear it, so tell me which cues to check.
```

## 10. Finish

```
Do a critical review of the whole film as if you were not the one who made it.
List what is still weak, fix what you can, and tell me what only I can judge.
```
